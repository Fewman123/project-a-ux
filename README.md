# Project A — структура сайта и user flow

Документ описывает UX-каркас многостраничного сайта Project A: три модели премиальной
мебели для кошек, собственное производство, запуск через лист ожидания и предзаказ.

Это не дизайн-макет. Визуальный язык, логотип, палитра и типографика — зона брендинговой
студии. Здесь только структура, потоки и логика страниц.

## Что внутри

- **Три решения**, на которых держится вся карта: `/early-access` как один URL на две фазы,
  постоянные адреса моделей, конфигурация сохраняется в заявку, а не в корзину.
- **Карта сайта** — 8 содержательных страниц, 4 служебных, 404, приоритеты P0/P1/P2
  и список того, чего на старте сознательно нет.
- **Потоки** — шесть входов на сайт и путь каждого до заявки.
- **Жизненный цикл листа ожидания** — семь шагов от заявки до таймлайна заказа.
- **Две фазы `/early-access`** — лист ожидания → предзаказ → пауза, переключение контентом.
- **Подборщик модели** — три вопроса с весами и выдача рекомендации.
- **Спецификация страниц** — задача каждой страницы, блоки и единственное главное действие.

## Как смотреть

Открыть `index.html` в браузере. Внешних зависимостей нет, кроме шрифтов Google Fonts.
Страница адаптивна и поддерживает тёмную тему.

## Открытые вопросы

- Названия моделей и slug — рабочая заглушка (`nest-s`, `nest-m`, `nest-l`).
- Цены на старте не называются: их первыми узнают участники листа ожидания.
- Платёжный провайдер и способ предоплаты — решение принимается к моменту предзаказа.
